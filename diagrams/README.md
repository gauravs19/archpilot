# Archpilot Diagram Archetypes

A library of perfectly formatted, copy-paste ready Mermaid diagrams for enterprise architecture documents. These archetypes are specifically designed to look clean in both light and dark mode GitHub environments.

## Available Archetypes

1. **[01-c4-context-archetype.md](./01-c4-context-archetype.md)**: Standard C4 Context/Container level diagram showing user personas interacting with system components.
2. **[02-saga-choreography-archetype.md](./02-saga-choreography-archetype.md)**: A sequence diagram demonstrating the Saga pattern (Choreography) with distributed rollbacks.
3. **[03-active-active-failover.md](./03-active-active-failover.md)**: Global multi-region routing and replication topology.

## Guidelines for AI Agents
When generating a `design.md`, do not guess Mermaid syntax. Read the relevant archetype from this folder, substitute the component names with the specific project requirements, and output the result.
