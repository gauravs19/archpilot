# Contributing to Archpilot

Thanks for your interest in contributing. Archpilot is an open standards library — contributions that improve coverage, correctness, or usability of enterprise architecture rules are welcome.

## Ways to Contribute

- **Add or improve a standard** — new rules, templates, or personas in `/standards`
- **Fix a mistake** — incorrect guidance, outdated patterns, broken examples
- **Improve docs** — clearer explanations, better examples, missing context

## Process

1. Fork the repo and create a branch: `git checkout -b my-improvement`
2. Make your changes
3. Open a PR with a short description of what changed and why

## Standards for Standards

When adding or editing a rule:
- Cite a source or real-world rationale — no unsupported opinions
- Keep language precise and actionable, not advisory
- If it conflicts with an existing rule, note the tradeoff explicitly

## Questions

Open a [Discussion](https://github.com/gauravs19/archpilot/discussions) — not an issue — for questions, ideas, or design conversations.
